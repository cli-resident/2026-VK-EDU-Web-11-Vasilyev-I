# AskRu

ДЗ1: статическая вёрстка сайта вопросов и ответов.

Открыть `public/index.html` в браузере. Интернет и установка зависимостей не нужны.

Страницы:
- `base.html` — общий макет;
- `index.html` — список вопросов;
- `hot.html` — популярные вопросы;
- `tag.html` — вопросы по тегу;
- `question.html` — вопрос и ответы;
- `ask.html` — создание вопроса;
- `login.html` — вход;
- `signup.html` — регистрация;
- `profile.html` — настройки профиля.

Все HTML находятся в `public/`. Bootstrap 5.3.3 и собственные стили лежат в `public/static/css/`, скрипт — в `public/static/js/`, изображения — в `public/static/img/`.

Формы, голосования и пагинация демонстрационные. Данные на сервер не отправляются. На страницах входа и регистрации показаны примеры ошибок.
